# Treinos

App de treinos para celular: fichas, registro de carga por série, timer de descanso, vídeos de execução e histórico.
Funciona sem internet depois de instalado e guarda tudo no próprio aparelho.

## Instalar no iPhone
1. Abra o endereço do app no Safari.
2. Toque em Compartilhar e depois em Adicionar à Tela de Início.

## Fichas
Em Ajustes > Importar ficha, cole o JSON da ficha. Use "Copiar o formato" no próprio app para pedir fichas no chat.

## Publicar no GitHub Pages
Settings > Pages > Deploy from a branch > `main` / root.

Ao mudar qualquer arquivo do app, aumente `VERSAO` em `sw.js` para o celular baixar a versão nova.
